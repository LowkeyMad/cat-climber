# Cat Climber

Cat Climber is a Godot 4.4.1 prototype about a mustached rider on an orange lasagna-loving cat racing through lasagna fields.

## Run locally

Open this folder in Godot 4.4.1 and run `main.tscn`.

## Controls

- Jump: Space
- Pounce: Up Arrow
